Studio / Quick start

A small start.
A working program.

Create and run your first blueprint in the Slang studio.

  1. Create your account.

    Open slang.run, choose Sign up, and save the recovery code. You will need it if you forget your password; email recovery is not enabled.

  2. Start with Echo.

    In Blueprints, create a blueprint, select the Echo template and choose Use template. Open it in the studio.

  3. Run something real.

    Press Test, enter "Hello Slang" in Input, and press Submit. The Go engine runs your blueprint and returns the same value in Output.

  4. Save and deploy.

    Connect operators and save your changes. Return to the blueprint, select Add deployment, choose REST-API and deploy. The deployment page shows your HTTPS address and execution history.

Private editing, public deployments.

Saved blueprints and studio tests belong to your account. A REST-API deployment can be invoked by anyone with its URL, using an HTTP POST with Content-Type: application/json. Never put secrets in public responses. Stop or remove deployments you no longer need.
